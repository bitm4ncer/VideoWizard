# Style-Karte: Clean Tutorial

Ruhige, sachliche Karte fuer Erklaervideos. Selbst formuliert; Lizenz MIT,
Version 1; Aenderungen erhoehen die Version in `blocks/index.json`.

## Palette

| Rolle | Wert | Einsatz |
|---|---|---|
| Grund | #F5F7FA | Flaeche und Hintergrund |
| Text | #1B1F24 | Titel und Fliesstext |
| Akzent | #2F6FED | Hervorhebung, Cursor, aktives Element |
| Signal | #E4572E | Warnung, hoechstens einmal pro Video |

## Typografie

- Eine Familie: Inter; Titel in 600, Text in 400.
- Titel 44 px, Fliesstext 28 px, Sprecherzeile 32 px (Bezug: 1080p).
- Hoechstens zwei Gewichte; keine dekorativen Schriften.

## Motion

- Schnitte weich mit 200 ms ease-in-out; hart nur beim Themenwechsel.
- Detail-Zoom bis 1,15-fach, Anstieg 300 ms, ohne Wackeln.
- Einblendungen ohne Bounce, 150 ms.

## Grading

- Hell und neutral: Saettigung 95 Prozent, Weisspunkt leicht kuehl.
- Hautton nicht anfassen; Kontrast sanft anheben.
- Bildschirmaufnahmen nicht nachschaerfen, sonst franst die Schrift.

## Regeln

- Eine Aussage pro Shot, ein Fokuspunkt je Bild.
- Akzentfarbe sparsam: hoechstens ein Akzentelement je Shot.
- Uebergaenge nur, wo sie eine Aussage tragen.
- Text nie unter 24 px; die Safe-Zone unten 15 Prozent frei halten.

## Frame-Checkliste

1. Genau ein Fokuspunkt im Bild?
2. Schrift auch bei 50 Prozent Zoom lesbar?
3. Safe-Zone frei von Text?
4. Alle Farben aus der Palette?
5. Traegt der Uebergang eine Aussage?
