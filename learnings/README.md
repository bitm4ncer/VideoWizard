# Belegarchiv

Hier liegt je Erkenntnis eine datierte Datei `JJJJ-MM-TT-<slug>.md` mit
Beobachtung, Beleg, Ergebnis und offener Frage. Den Rahmen legt
`vz learn "<Titel>" [--source "<Quelle>"] [--note "<Beobachtung>"]` an.

`learnings/` ist ein Belegarchiv, kein Tagebuch: jeder Eintrag nennt Quelle und
Beleg, nichts wird erfunden. Ein vorhandener Eintrag wird nie ueberschrieben,
und eingearbeitete Erkenntnisse werden markiert, nicht geloescht: der Status
geht von `offen` auf `eingearbeitet`, die Datei bleibt.
